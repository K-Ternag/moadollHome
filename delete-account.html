01계정 없이 사용하는 모아돌

현재 모아돌(com.moadoll)은 회원가입이나 서버 계정을 만들지 않습니다. 따라서 탈퇴할 모아돌 계정은 없으며, 이 페이지는 기기 데이터·이미지·백업·문의 기록의 삭제 방법을 안내합니다. 이 홈페이지에서 기기 데이터를 원격으로 지우지는 않습니다.

02인형·포토카드 개별 삭제

내 인형 목록에서 삭제할 인형을 고르고 삭제 기능을 사용하세요. 저장된 포토카드는 스튜디오의 불러오기 목록에서 선택하여 삭제할 수 있습니다. 한 항목을 지워도 편집 초안이나 다른 카드에 담긴 인형, 별도로 저장한 PNG는 남을 수 있습니다.

03기기의 앱 데이터 전체 삭제

Android 설정 → 앱 → 모아돌 → 저장공간(또는 저장공간 및 캐시) → 데이터 삭제(또는 저장공간 비우기)를 선택하세요. 인형, 카드, 초안, 이전 기록과 설정 등 앱 전용 데이터가 초기화됩니다. ‘캐시 삭제’만으로는 전체 데이터가 지워지지 않습니다. 기기마다 메뉴 이름은 다를 수 있습니다. 삭제한 편집 데이터를 앱에서 되돌릴 수 없으므로 필요한 이미지는 먼저 저장하세요.

04갤러리와 공유 이미지 삭제

갤러리 또는 파일 앱에서 MoaDoll 앨범/Pictures/MoaDoll의 PNG를 삭제하고 필요하면 휴지통도 비우세요. 다른 위치에 저장한 사본과 사진 백업 서비스의 사본은 별도로 관리해야 합니다. 메신저·SNS로 공유한 이미지는 해당 서비스에서 삭제하세요. 수신자가 저장한 사본은 개발자가 삭제할 수 없습니다.

05시스템 백업 확인

Android 설정의 백업 및 연결된 Google 계정 또는 제조사 백업 설정에서 백업을 확인하고, 제공자가 지원하는 방법으로 관리·삭제하세요. 앱 제거 또는 데이터 삭제가 기존 클라우드 백업까지 즉시 지우는 것은 아닙니다. 재설치·기기 이전 과정에서 기존 백업이 복원될 수 있으므로 관련 복원 설정도 확인하세요.

06문의 기록 삭제 요청

공개 문의 이메일이 안내되어 있다면, 문의할 때 사용한 이메일 주소로 ‘모아돌 문의 기록 삭제 요청’을 보내 주세요. 기존 문의 일자와 제목처럼 요청 확인에 필요한 최소 정보만 포함하세요. 기기의 인형이나 카드 파일을 첨부할 필요는 없습니다. 처리 범위와 결과는 이메일로 안내하며, 정해진 문의 기록 보관 기간은 개인정보처리방침에서 확인할 수 있습니다.
