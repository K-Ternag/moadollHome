01적용 범위

이 방침은 모아돌(MoaDoll, Android 패키지 com.moadoll)과 소개 홈페이지에 적용됩니다. 현재 앱은 로그인·회원가입, 광고, 앱 내 결제, 개발자 서버 전송 및 분석 SDK를 사용하지 않습니다. 기기 내 저장, Android가 제공하는 백업, 사용자가 직접 선택하는 공유, 홈페이지 접속과 문의는 아래와 같이 구분합니다.

02기기에서 처리하는 데이터

인형의 이름·외형·착장, 편집 초안, 포토카드의 배치·배경·프레임·문구·스티커·말풍선·저장 시각, 언어·튜토리얼 설정을 기능 제공과 작업 이어하기에 사용합니다. 이전 버전의 보유 아이템·포인트·선물 이력도 기기에 남을 수 있습니다. 이러한 편집 데이터와 설정은 앱의 기기 내 데이터베이스 및 설정 저장소에 보관되며 개발자 서버로 전송하지 않습니다. 사용자가 카드 문구에 직접 개인정보를 입력하면 저장 이미지에도 포함될 수 있습니다.

03이미지 저장과 공유

이미지 저장을 선택하면 PNG를 갤러리의 Pictures/MoaDoll 등에 저장하고 작업 중 임시 파일을 만들 수 있습니다. 공유 시 Android 공유창에서 사용자가 고른 앱에 해당 이미지의 읽기 권한을 일시적으로 제공합니다. 해당 서비스에 전송된 이미지와 수신자가 보관한 사본에는 그 서비스의 정책이 적용됩니다. 친구 카드도 같은 방식으로 동작하며 친구 목록이나 초대 추적 정보를 만들지 않습니다.

04Android 시스템 백업과 기기 이전

앱은 Android 자동 백업과 기기 이전을 허용하며, 데이터베이스와 설정 데이터가 백업 대상에 포함됩니다. 기기 설정·운영체제·백업 제공자에 따라 Google 등 시스템 백업 제공자가 이를 처리하거나 새 기기로 복원할 수 있습니다. 이는 개발자 서버 동기화와 별개입니다. 백업의 사용 여부와 삭제는 기기 및 백업 제공자의 설정에서 관리하며, 앱 데이터 삭제만으로 이미 만들어진 백업이 즉시 삭제된다고 보장하지 않습니다.

05권한과 접근

Android 8·9에서는 이미지를 공용 저장소에 저장하기 위해 저장소 쓰기 권한을 요청할 수 있습니다. Android 10 이상은 시스템 미디어 저장 기능을 이용합니다. 현재 앱은 인터넷·광고 ID·위치·연락처·카메라·마이크 권한을 선언하지 않습니다. 선택 권한을 거절하면 관련 저장 기능이 제한될 수 있으며, Android 설정에서 권한을 변경할 수 있습니다.

06홈페이지와 문의

홈페이지 자체에는 분석·광고 스크립트, 쿠키, 회원가입, 문의 내용을 수집하는 서버가 없습니다. GitHub Pages는 서비스 보안 목적으로 방문 IP 주소를 기록할 수 있습니다. 외부 Google Play 링크를 열거나 메일을 보내면 해당 서비스의 정책이 적용됩니다. 공개 문의 이메일로 연락한 경우 발신 이메일, 사용자가 제공한 이름·문의 내용·첨부파일을 회신과 문제 해결에 사용합니다. 문의 시 필요한 정보만 보내 주세요.

07보관과 삭제

기기 내 데이터는 사용자가 앱에서 삭제하거나 Android 설정에서 앱 데이터를 삭제할 때까지 보관됩니다. 개별 항목 삭제는 다른 초안·카드에 포함된 정보, 과거 장면, 임시 파일, 별도 PNG 또는 백업을 모두 삭제하는 기능이 아닙니다. 전체 초기화 방법은 데이터 삭제 안내를 참고하세요. 문의 기록 보관 기간: 출시 전 확정 예정. 시스템 백업, 공유 대상과 GitHub 접속 기록의 보관·삭제는 각 제공자의 정책과 사용자의 설정에 따릅니다.

08정보 관리와 보호

앱의 편집 내용은 앱 전용 저장소에서 관리합니다. 내보낸 이미지와 공유 사본은 앱 전용 저장소 밖에 남을 수 있습니다. 인형·카드는 앱에서 확인하고 수정·삭제할 수 있고, 문의 기록의 열람·정정·삭제·처리 정지는 공개 문의 이메일로 요청할 수 있습니다. 필요한 최소 범위에서 본인 확인을 요청할 수 있으며, 개발자는 사용자의 기기나 외부 공유 사본을 원격으로 삭제할 수 없습니다.

09아동의 정보와 정책 변경

현재 앱은 연령·계정·연락처를 요구하지 않습니다. 아동도 카드 문구나 문의에 이름·학교·연락처 같은 개인정보를 넣지 않도록 보호자가 도와주세요. 아동이 문의를 통해 제공한 개인정보의 삭제는 보호자가 문의 창구로 요청할 수 있습니다. 기능과 처리 방식이 변경되면 이 페이지와 시행일을 갱신하고 필요한 경우 별도로 안내합니다. 적용 대상 연령과 이용 가능 지역은 출시 시 스토어 등록정보를 확인하세요.
